# 🔧 Исправление ошибки входа

## Проблема
Ошибка: "Failed to execute 'json' on 'Response': Unexpected end of JSON input"

## Причина
Фронтенд (localhost:5173) не мог подключиться к API (localhost:8787) из-за CORS и разных портов.

## Решение
✅ Настроен прокси в `vite.config.ts` - теперь все запросы к `/api` автоматически перенаправляются на `localhost:8787`

## Что нужно сделать:

### Вариант 1: Перезапустить фронтенд (рекомендуется)

1. Найдите терминал, где запущен фронтенд
2. Нажмите `Ctrl+C` чтобы остановить
3. Запустите снова:
   ```bash
   cd frontend
   npm run dev
   ```

### Вариант 2: Просто обновить страницу

Иногда Vite автоматически подхватывает изменения конфига. Попробуйте:
- Обновить страницу в браузере (F5)
- Или жёсткое обновление (Ctrl+Shift+R)

## Проверка

После перезапуска попробуйте войти снова:
- Email: `admin@test.com`
- Пароль: `admin123`

## Если всё ещё не работает:

1. Убедитесь, что Workers запущен:
   ```bash
   curl http://localhost:8787/api/auth/login -X POST -H "Content-Type: application/json" -d '{"email":"admin@test.com","password":"admin123"}'
   ```
   Должен вернуть JSON с токеном.

2. Проверьте, что фронтенд использует прокси:
   - Откройте DevTools (F12)
   - Вкладка Network
   - Попробуйте войти
   - Запрос к `/api/auth/login` должен идти через прокси

3. Если прокси не работает, создайте файл `frontend/.env.local`:
   ```
   VITE_API_BASE=http://localhost:8787/api
   ```
   И перезапустите фронтенд.
