# 🚀 CRM System - Портфолио проект

## 📋 Описание проекта

**Полнофункциональная CRM система для управления заявками** с современным веб-интерфейсом, REST API, интеграцией Telegram и развёртыванием на Cloudflare Workers.

### Ключевые особенности:
- ✅ **10+ публичных страниц** (главная, услуги, тарифы, блог, о нас и др.)
- ✅ **Личный кабинет** с авторизацией и системой ролей
- ✅ **Тёмная/светлая тема** с автоматическим переключением
- ✅ **Управление заявками** с фильтрацией, поиском и статусами
- ✅ **Расширенная аналитика** с графиками и статистикой
- ✅ **Telegram бот** с интерактивными кнопками
- ✅ **Экспорт данных** в CSV и JSON
- ✅ **Адаптивный дизайн** для всех устройств
- ✅ **Полная интеграция** Frontend + Backend + Database

## 🛠️ Технологический стек

### Frontend
- **React 18** + **TypeScript** - современный UI фреймворк
- **Vite** - быстрая сборка и разработка
- **React Router** - маршрутизация
- **CSS Variables** - поддержка темной темы
- **Адаптивный дизайн** - мобильная версия

### Backend
- **Cloudflare Workers** - serverless API
- **TypeScript** - типизированный код
- **itty-router** - маршрутизация
- **JWT** - авторизация
- **D1 Database** - SQLite в облаке

### Интеграции
- **Telegram Bot API** - уведомления и управление
- **REST API** - полный набор endpoints

### Deployment
- **Cloudflare Workers** - backend
- **Cloudflare Pages** - frontend
- **Cloudflare D1** - database

## 📊 Функциональность

### Публичная часть (10+ страниц)
1. **Главная** - hero секция, возможности, CTA
2. **Услуги** - описание функционала
3. **Тарифы** - планы и цены
4. **Как это работает** - пошаговый процесс
5. **О нас** - информация о проекте
6. **Блог** - статьи и новости
7. **Контакты** - форма заявки
8. **Вход** - авторизация

### Личный кабинет
- **Панель управления** - дашборд со статистикой
- **Управление заявками** - список, фильтры, поиск
- **Детальная страница заявки** - полная информация, комментарии, история
- **Аналитика** - графики, статистика, отчёты
- **Настройки** - профиль, тема, уведомления, экспорт

### API Endpoints
- `POST /api/public/request` - создание заявки
- `POST /api/auth/register` - регистрация
- `POST /api/auth/login` - вход
- `GET /api/auth/me` - текущий пользователь
- `GET /api/requests` - список заявок
- `GET /api/requests/:id` - детали заявки
- `PUT /api/requests/:id/status` - изменение статуса
- `POST /api/requests/:id/comments` - комментарии
- `GET /api/analytics/stats` - статистика
- `GET /api/export/csv` - экспорт CSV
- `GET /api/export/json` - экспорт JSON
- `POST /api/telegram/webhook` - Telegram webhook
